OCEANIC AIRLINES - HTML5/CSS3 ASSIGNMENT

Project structure:
oceanic-airlines/
  index.html
  css/style.css
  images/hero.jpg

How to run:
1. Open the oceanic-airlines folder in VS Code.
2. Right-click index.html and choose "Open with Live Server".
3. Or double-click index.html to open it directly in a browser.

Notes:
- Navigation uses an HTML unordered list.
- Orange tabs have top arrows.
- On hover/focus, the arrow disappears and the tab pops up over 0.5 seconds.
- Hover uses both a fallback background color and a gradient/image.
- Includes HTML5 semantic elements, keyboard focus, alt text, responsive styles, and reduced-motion support.
