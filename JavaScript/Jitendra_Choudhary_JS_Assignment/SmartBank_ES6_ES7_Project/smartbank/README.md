# SmartBank JavaScript ES6/ES7 Assignment

## Problem statement
A responsive client-side banking portal supporting registration, login, accounts, deposits, withdrawals, transfers, transaction history, loan calculation and profile management.

## Technologies
HTML5, CSS3, JavaScript ES6/ES7 modules, Local Storage, Session Storage, Fetch API and JSON.

## Run
Because ES modules and Fetch API are used, start a local server in this folder. Example: `python -m http.server 8000`, then open `http://localhost:8000`.

Demo login: `demo` / `Demo@123`.

## Pages
Home, registration, login, dashboard, accounts, transfer, transactions, loan calculator and profile.

## ES6/ES7 demonstrated
Classes, modules, let/const, arrow functions, template literals, destructuring, spread, default parameters, Promises, async/await, map, filter, reduce, find, sort, JSON and exception handling.

## Important
This is a client-side simulation. Do not use real banking or sensitive information.
