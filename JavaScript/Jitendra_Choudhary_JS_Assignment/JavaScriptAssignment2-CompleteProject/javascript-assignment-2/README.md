# JavaScript Practical Assignment 2

A complete responsive project containing all 10 DOM, forms and event-handling exercises from the assignment PDF.

## Run
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.

## Folder structure
- `index.html` - all page sections
- `css/style.css` - responsive design
- `js/app.js` - validation, calculations and event handling
- `images/` - local gallery images
